# Music Player — отдельный локальный плеер

Устанавливаемый `.amaliaplug`, содержащий собственный движок Android MediaPlayer,
Compose-экран, библиотеку MediaStore, очередь и сохранённые плейлисты.
В хосте нет названий песен, маршрутов или логики этого плеера.

## Требования

Нужен обновлённый хост с API плагинов **2.1.0**: строковый заголовок ScreenSpec,
BackgroundWorkType.MEDIA_PLAYBACK, HostServices.ensureForeground и сохранённый R8 ABI.
Старое приложение отклоняет пакет по minHostVersion. Версия API хоста отличается от
маркетинговой версии приложения. После обновления хоста установите пакет через магазин
или из файла; вкладка «Музыка» появляется при включённом плагине.

На экране плеера разрешите чтение аудио. Для Android 13+ используется READ_MEDIA_AUDIO,
для Android 12 и ниже — READ_EXTERNAL_STORAGE. Доступ к уведомлениям других приложений
не требуется. Библиотека показывает аудио, помеченное MediaStore как музыка; файлы,
недоступные MediaStore (например, приватный каталог другого приложения), не видны.

## Возможности

- Библиотека с нажимаемыми строками песен и отдельным режимом выбора для плейлистов.
- Закреплённый мини-плеер с паузой и переключением трека; нажатие на название открывает
  развёрнутый плеер с обложкой из метаданных, перемоткой, случайным порядком и повтором.
  При отсутствии обложки показывается нейтральный значок. Обложки декодируются вне UI-потока.
- Поиск по названию, исполнителю и альбому; «Слушать всё» учитывает текущий фильтр.
- Отдельный поиск плейлистов; пустые очередь и плейлист ведут к библиотеке.
- Воспроизведение собственным MediaPlayer, перемотка, предыдущий/следующий трек,
  случайный порядок, повтор песни или очереди.
- Системная MediaSession, аудиофокус, пауза при отключении наушников.
- Подготовка foreground типа mediaPlayback до начала звука, уведомление с действиями.
- Создание плейлистов, добавление/удаление выбранных песен, удаление плейлиста.
  Удаление плейлиста не удаляет аудиофайлы. Плейлисты хранятся в SharedPreferences
  внутри данных приложения, отдельно от пакета, и сохраняются при его обновлении.
- Переводы внутри пакета: ru/en/ja/de/es/fr/zh/hi/ar.
- Выключение/удаление плагина останавливает и освобождает его движок.

Очередь и позиция воспроизведения живут в процессе; после принудительного завершения
процесса музыка автоматически не возобновляется. Экран содержит вкладки песен,
плейлистов и очереди; отдельные каталоги альбомов/исполнителей пока не выделены,
они доступны через поиск по метаданным.

## Доступ ИИ

`ToolContributor` публикует инструменты динамически:

- `music_library`, `music_status`, `music_queue`;
- `music_play`, `music_control`, `music_seek`, `music_shuffle`, `music_repeat`;
- `music_playlists`, `music_playlist_create`, `music_playlist_add`,
  `music_playlist_remove`, `music_playlist_delete`, `music_playlist_play`.

Сначала ИИ ищет реальные треки, затем использует возвращённые ID. Параметр `track_ids`
— JSON-массив ID, закодированный строкой, максимум 100 за вызов. Выдача постраничная,
до 100 элементов. Неоднозначный запрос `music_play(query=...)` возвращает кандидатов
без самовольного выбора. ИИ не анализирует звучание: жанр/настроение из неизвестного
файла не выдумываются. Создание плейлиста по исполнителю возможно по метаданным.

## Сборка

JDK 17, Gradle **8.10.2**, Android SDK platform **35**, build-tools **35.0.0**.
Kotlin/Compose compiler **2.2.10**, зависимости Compose соответствуют хосту.
Для DEX закреплён D8/R8 **8.10.21** (скачивается Gradle); старый D8 из build-tools
не поддерживает метаданные Kotlin 2.2. Таблица совместимости:
https://developer.android.com/build/kotlin-support
Собирается только JVM JAR плагина — APK не нужен.

```bash
export ANDROID_HOME=/path/to/android-sdk
export GRADLE_BIN=/path/to/gradle-8.10.2/bin/gradle
bash examples/music-player-kotlin/pack.sh
```

Выход: `examples/music-player-kotlin/dist/music-player.amaliaplug`.
В GitHub Actions выберите `Build plugin package`, example=`music-player-kotlin`.
Контракты, Compose, Kotlin и coroutines подключены compileOnly и не включаются в DEX.
Собственные локализованные assets включаются общим упаковщиком SDK.

На устройстве необходимо проверить разрешения (включая отказ и возврат из настроек),
воспроизведение с погашенным экраном, аудиофокус, кнопки уведомления, Bluetooth/наушники,
большую медиатеку и инструменты ИИ. Успешная компиляция этих проверок не заменяет.
